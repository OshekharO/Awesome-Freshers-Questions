# Universal UI/UX Design Prompt Template

Here's a comprehensive prompt template that captures the Game Hub design principles without mentioning the specific project:

## **Universal Modern Website Design Prompt**

```
Create a modern, engaging website with these design characteristics:

**VISUAL DESIGN LANGUAGE:**
- Clean, card-based interface with subtle depth (shadows and rounded corners)
- Vibrant gradient color schemes with primary and accent colors
- Dual theme support (light/dark mode) with smooth transitions
- Ample white space and modern typography (preferably Poppins or similar)
- Consistent 12px border radius and subtle box shadows throughout
- Smooth micro-animations (0.3s ease transitions)

**LAYOUT & STRUCTURE:**
- Hero section with gradient background and compelling value proposition
- Feature/content cards with hover lift effects (translateY movement)
- Clear section hierarchy with decorative underline accents
- Responsive grid system that adapts seamlessly across devices
- Sticky navigation with brand identity
- Comprehensive footer with social integration

**INTERACTIVE EXPERIENCE:**
- Subtle hover animations on all interactive elements
- Smooth scrolling navigation between sections
- Dynamic back-to-top button that appears on scroll
- Loading states and purposeful micro-interactions
- Mobile-optimized touch targets and gestures

**TECHNICAL IMPLEMENTATION:**
- Bootstrap 5 framework for responsive layout
- CSS custom properties for consistent theming
- Font Awesome icon integration
- Mobile-first responsive approach
- Performance-optimized assets and code
- Accessibility compliance (WCAG guidelines)

Create a [type of website] for [specific purpose/industry] that embodies these modern web design principles while maintaining appropriate branding and content structure.
```

## **Alternative Quick Reference Version:**

```
Design a website using these modern UI/UX principles:

**STYLE GUIDE:**
- Colors: Vibrant gradients, light/dark theme variants
- Typography: Clean, modern sans-serif (Poppins preferred)
- Layout: Card-based with 12px border radius and subtle shadows
- Interactions: 0.3s ease transitions, hover lift animations
- Components: Feature cards, gradient hero, sticky nav, social footer

**TECH STACK:**
- Bootstrap 5 responsive grid
- CSS custom properties for theming
- Font Awesome icons
- Mobile-first approach

**KEY FEATURES:**
- Dark/light mode toggle
- Smooth scrolling navigation
- Responsive card layouts
- Engaging hover effects
- Professional footer design

Create a [website type] that follows this design system for [specific use case].
```

## **Component-Specific Prompt:**

```
Build a [specific component] with these design attributes:

**VISUAL STYLE:**
- Modern card layout with subtle shadows
- Rounded corners (12px border radius)
- Smooth hover animations (translateY movement)
- Clean typography hierarchy
- Gradient or solid color backgrounds

**INTERACTIONS:**
- 0.3s ease transitions
- Responsive across devices
- Accessible focus states
- Mobile-friendly touch targets

**TECHNICAL:**
- Bootstrap 5 compatible
- CSS custom properties for colors
- Font Awesome icon support
- Cross-browser compatible
```

## **The Core Design Principles to Reference:**

Instead of saying "Game Hub style," you can describe these key characteristics:

1. **"Modern card-based design with hover animations"**
2. **"Gradient color schemes with dark/light mode support"**
3. **"Clean, spacious layout with smooth interactions"**
4. **"Bootstrap 5 responsive framework with custom theming"**
5. **"Engaging micro-interactions and mobile-optimized UX"**

## **Example Usage:**

*"Create a portfolio website using modern card-based design with hover animations, gradient color schemes supporting dark/light mode, and Bootstrap 5 responsive framework."*

*"Design a SaaS landing page with clean card layouts, smooth hover effects, gradient hero section, and comprehensive footer with social integration."*

This approach gives you the same design quality without being tied to any specific project reference!
