# GitHub Integration Prompts for Future Projects

Here are ready-to-use prompts you can save for when you want to integrate GitHub features into other websites:

## 🚀 **For GitHub Issues Integration**

```
I want to add GitHub Issues integration to my website to allow users to:

1. Report bugs/issues directly from the website
2. Submit feature requests
3. Report content problems
4. Suggest improvements

The website is hosted on GitHub Pages (static). Please implement:

- Modal forms for different types of submissions
- Pre-filled GitHub issue creation with templates
- User-friendly form validation
- Success feedback to users
- GitHub labels and assignees automation

Make it work with this GitHub repository: [REPO_OWNER/REPO_NAME]

Include:
- Issue templates in .github/ISSUE_TEMPLATE/
- Client-side JavaScript for form handling
- Bootstrap 5 modals for forms
- Proper error handling
```
