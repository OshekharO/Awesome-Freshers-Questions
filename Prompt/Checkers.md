# UI/UX Design Prompt for Account Checker Applications

Based on your Chaupal Account Checker code, here's a comprehensive design prompt you can apply to other projects:

## Design System Prompt

### Core Visual Identity
```
Create a dark-themed, technical interface with:
- Primary background: #26272c (dark charcoal)
- Text color: #616370 (soft gray)
- Accent colors: Success (#198754), Danger (#dc3545)
- Monospace font family for technical elements
- Minimalist, functional aesthetic
```

### Layout Structure
```
Implement a centered container layout with:
- Prominent header/title at top center
- Main content area with clear visual hierarchy
- Form controls grouped logically
- Results displayed in categorized sections
- Footer with attribution/branding
```

### Component Specifications

#### Input Area
```
Design a large text input area with:
- Clear label using badge-style formatting
- Generous vertical space (10+ rows)
- Placeholder text showing expected format
- Monospace font for technical data entry
- Responsive design that works on mobile
```

#### Control Buttons
```
Create action buttons with:
- Clear primary/secondary actions
- Visual feedback states (enabled/disabled)
- Danger color for destructive actions
- Success color for positive actions
- Centered positioning with adequate spacing
```

#### Results Display
```
Design results containers with:
- Clear section headers with badge counters
- Scrollable content areas (max-height: 300px)
- Categorical organization (valid/invalid)
- Monospace formatting for technical data
- Visual separation between result items
```

### User Experience Principles
```
Focus on:
- Instant visual feedback for all actions
- Clear status indicators (counters, colors)
- Progressive disclosure of information
- Error prevention with format examples
- Performance optimization for batch processing
```

### Technical Implementation Notes
```
Ensure:
- Mobile-responsive design
- Accessible color contrast
- Fast-loading, minimal dependencies
- SEO-optimized structure
- Cross-browser compatibility
```

### Branding Elements
```
Include:
- Consistent footer attribution
- Favicon and touch icons
- Open Graph meta tags for sharing
- Structured data for search engines
```

This design system creates a professional, technical-looking interface perfect for account verification tools, batch processors, or any application that needs to handle lists of credentials with clear valid/invalid categorization.
